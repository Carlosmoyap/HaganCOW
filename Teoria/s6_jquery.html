1. Cercar en l'arbre del DOM

Estructura HTML

<body>
  <h1>Where do you want to go?</h1>
  <p>Plan your next adventure.</p>
</body>

Llegir el text del node (.text()):

$("h1").text(); 
// Retorna: "Where do you want to go?"

Canviar el text del node:

$("h1").text("Where to?");

El Node al Document

DOCUMENT
└─ html
   ├─ head
   └─ body
      ├─ h1
      │  └─ "Where to?"
      └─ p
         └─ "Plan your next adventure."

Equivalència JS Modern

document.querySelector("h1").textContent = "Where to?";

2. Seleccionar múltiples nodes

Llista de Destinacions

<ul id="destinations">
  <li>Rome</li>
  <li>Paris</li>
  <li class='promo'>Rio</li>
</ul>
  • $("li").text("Orlando");
    Canvia TOTS els elements <li> alhora.
  • $("#destinations");
    Selecciona per ID (Només l'ul).
  • $(".promo");
    Selecciona per Classe (El node "Rio").

Seleccions Híbrides i Descendents

  • $(".promo, #france");
    Selecciona varis elements combinant regles.
  • $("#destinations li");
    Qualsevol li descendent.
  • $("#destinations > li");
    NOMÉS els fills directes.

JS Modern: querySelectorAll

JS Natiu ja suporta CSS sencer:

document.querySelectorAll("#destinations > li, .promo");

3. Filtres i Jerarquia de Nodes

Filtres de Posició

  • $("li:first"); o $("li").first();
  • $("li:last"); o $("li").last();
  • $("li:odd"); (Senars: index 1 - Paris)
  • $("li:even"); (Parells: index 0, 2 - Rome, Rio)

Navegar per Jerarquia

  • $("li").first().parent(); (Puja al node pare)
  • $("li").first().next(); (Salta de Rome a Paris)
  • $("#dest").find("li"); (Cerca qualsevol descendent)
  • $("#dest").children("li"); (Cerca només fills directes)

L'Arbre Recorregut

ul #destinations
 ├─ li #0 (first) (even)
 │  └─ Rome
 ├─ li #1 (next) (odd)
 │  └─ Paris
 └─ li #2 (last) (even)
    └─ Rio

JS Modern

el.nextElementSibling el.parentElement el.children

4. Afegir i moure nodes

Crear un Node

// Crea el node a memòria però NO el posa al DOM:
var price = $('<p>From $399</p>');

Mètodes d'Inserció (Errors típics)

  • $('.vacation').before(price);
    NO! El col·loca a fora, abans de l'element.
  • $('.vacation').after(price);
    NO! El col·loca a fora, després.
  • $('.vacation').prepend(price);
    El col·loca a dins, però al principi de tot.

La Solució: Append

var price = $('<p>From $399</p>');

// CORRECTE! Afegeix al FINAL, per dins.
$('.vacation').append(price);

// Alternativa inversa:
price.appendTo($('.vacation'));

JS Modern

L'API de DOM nativa ha copiat literalment aquests noms:

element.append(node) element.prepend(node)

5. Esdeveniments i Eliminar nodes

Events No Obstructius

No fem servir onclick="" a l'HTML.

$(document).ready(function() {

  // Quan es faci clic a un botó...
  $('button').on('click', function() {
    var preu = $('<p>$399</p>');
    
    // S'afegeix just darrere
    $(this).after(preu); 
    
    // Elimina aquest botó en concret
    $(this).remove();
  });
  
});

Compte amb el Context Global

ERROR: $('button').remove();

Això eliminaria TOTS els botons de la web alhora. Per això utilitzem el referent relatiu $(this) per referir-nos només al node que ha disparat l'esdeveniment.

Altres funcions d'interès

  • alert('Hola'); Mostra un avís al navegador.
  • $('li').length; Retorna quants nodes compleixen la condició.

JS Modern

el.addEventListener('click', fn) el.remove()

6. Interacció amb formularis i càlculs

Llegint data- i formularis

<div class="vacation" data-price='399'>
  <input type='number' class='quantity' value='1'>
</div>
<span id='total'>399</span>

Utilitzarem keyup (quan l'usuari deixa anar una tecla) o change (quan canvia el valor de l'input).

La Lògica

$('.vacation').on('keyup change', '.quantity', function() {
  
  // .data() llegeix l'atribut data-price
  // El signe '+' converteix l'String a número
  var preu = +$(this).closest('.vacation').data('price');
  
  // .val() llegeix què ha escrit l'usuari
  var qtt = +$(this).val();
  
  // Actualitzem el text del resultat
  $('#total').text(preu * qtt);
});

JS Modern

let preu = el.closest('.vacation').dataset.price; let valor = inputEl.value;

7. Ressaltar i Animar (CSS vs jQuery)

Mètode obsolet: CSS en línia

// Funciona, però barreja estètica i programació
$(".box").css({
  'background-color': '#556633',
  'border': '2px solid red'
});
$(".box").show(); // Treu el display:none

Mètode Recomanat: Classes

// Afegeix la classe per activar regles del full CSS
$(".box").addClass('highlighted');

// Alterna la classe (posa-la si no hi és, treu-la si hi és)
$(".box").toggleClass('highlighted');

Efectes i Animacions

jQuery integrava mètodes per animar l'alçada o l'opacitat: .slideDown(), .fadeIn().

// Anima cap amunt de forma fluida (ms)
$(".box").animate({'top': '-10px'}, 400);

Substituït per CSS3

La funció animate() consumia molta CPU i bloquejava el fil principal. Avui les animacions es fan afegint una classe i usant Transicions CSS3 que fan servir la targeta gràfica (GPU).

8. Comunicació AJAX

Què és l'AJAX?

Permet recuperar dades (XML, JSON, HTML) del servidor de forma asíncrona sense recarregar la pàgina (ex: Gmail, Google Maps).

Carregar blocs: .load()

$("#resultat").load("fitxer.html");

Solucionar conflictes del Símbol $

// Si usem altres llibreries que empren el $
var jq = $.noConflict();
jq("p").hide();

Petició GET vs POST

// GET: Recupera informació via URL (?q=1)
$.get("getuser.php?q=1", function(dades) {
  $("#info").html(dades);
});

// POST: Envia dades protegides i sense límit
$.post("save.php", 
  { nom: "Pere", edat: 30 }, 
  function(res) { alert("Guardat!"); }
);

Fetch API Natiu

fetch('api.php').then(r => r.json()).then(...)

Interaccions

Afegeixen comportaments avançats de ratolí. Es pot fer llistes sortable, elements resizable i drag & drop amb una línia de codi.

10. jQuery UI: Draggable i Droppable

Draggable (Arrossegable)

Amb $("#elem").draggable(); podem moure qualsevol node per la pantalla.

  • Constrained: { axis: "x" } o { containment: "parent" } restringeix per on pot viatjar.
  • Delay: Espera temps abans d'activar-se per no confondre's amb un simple clic.
  • Esdeveniments: Pot escoltar quan comença (start), quan es mou (drag), i en deixar-ho anar (stop).

Droppable (Àrea receptora)

Es combina per crear la mecànica "Drag & Drop".

$("#brossa").droppable({
  accept: '.arxiu', // Filtre de què hi entra
  drop: function(event, ui) {
    // Elimina l'element quan entra
    ui.draggable.remove();
    $(this).addClass("ple");
  }
});

Molt típic en gestors de fitxers o en afegir productes a la cistella de la compra arrossegant-los.

11. jQuery UI: Interaccions Avançades

Resizable (Redimensionable)

  • Afegeix "agafadors" als marges d'un `div` per canviar la seva amplada/alçada.
  • Helper (Ghost): Mostra una línia guia transparent en comptes de redimensionar el contingut en viu per estalviar CPU.

Selectable

  • Permet crear un quadre de selecció de fitxers dibuixant amb el ratolí o usant Ctrl+Clic.
  • Molt útil per marcar fotos per esborrar.

Sortable (Llistes Ordenables)

  • Permet agafar els elements <li> d'una llista i reordenar-los lliurement.
  • Connect list: Passar elements d'una llista (Taula A) a una altra (Taula B) com a un Kanban de Trello.
  • Portlets: Recrear vistes de panells d'escriptori on els mòduls de notícies, clima o calendaris es poden arrossegar i intercanviar posicions.

API Drag & Drop HTML5

L'atribut natiu draggable="true" i els events ondragstart i ondrop són ara l'estàndard web per fer això.

12. jQuery UI: Widgets (Accordion, Auto)

Accordion (Pestanyes Expansibles)

$("#accordion").accordion();

Tancava i obria blocs de contingut agrupats per encapçalaments de forma suau, ideal per a llistes de preguntes freqüents (FAQ).

Autocomplete

Cercador intuïtiu. Suggereix autocompletat mentre escrius llegint d'una matriu (Array) o fent peticions AJAX per cada lletra teclejada.

Dialogs (Modals) i Tooltips

  • Dialog: Finestres emergents completament estilitzades amb botons inferiors, que enfosquien el fons i bloquejaven l'usuari fins a prémer 'Acceptar'.
  • Tooltips: Substituïa els "title" lletjos del navegador per bafarades (balonets) estètics que seguien el cursor.

Elements Natius

<details> i <summary> per Accordions.
<dialog> per a finestres modals.

13. jQuery UI: Widgets (Dates, Control)

Datepicker (Calendari)

El giny estrella de jQuery UI. Mostrava un calendari emergent impecable per triar la data o rangs entre dos dies. Suportava internacionalització ràpida.

Slider, Spinner, Progressbar

  • Slider: Cursor lliscant per triar volum, o un rang amb dos tiradors (Ex: Preus entre $50 i $100).
  • Spinner: Input numèric clàssic amb fletxes d'increment.
  • Progress: Barra d'estat visual per a càrregues (%).
