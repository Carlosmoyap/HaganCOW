Transferència de Dades: XML

Estructures, Parseig DOM, Integració amb AJAX i PHP

Utilitza les fletxes per navegar

1. Què és XML?

Definició

  • XML significa EXtensible Markup Language.
  • És un esquelet per crear llenguatges amb delimitadors.
  • L'HTML ha estat creat per visualitzar dades; l'XML ha estat creat per transportar i emmagatzemar dades.
  • La sintaxi és molt semblant a l'HTML:
    <element attribute="value">content</element>

Característiques Clau

  • Els tags (etiquetes) de l'XML no són predefinits. Es poden inventar tags relacionats amb l'aplicació.
  • Permet definir objectes aniuats (jerarquies).
  • Permet representar estructures de dades complexes en una forma fàcil de llegir i "autodescriptiva".

2. Aplicacions i Ús de l'XML

Qui l'utilitza?

  • Els servidors web emmagatzemen dades com a fitxers XML.
  • Les Bases de Dades a vegades retornen resultats en XML.
  • Els Web Services (SOAP) utilitzen XML per comunicar-se.
  • És el format base per a RSS (News i Podcasts).
  • Format base per a gràfics (SVG), matemàtiques (MathML) i música.

Per què s'utilitza?

  • Permet la lectura i enviament de múltiples dades alhora sense haver de parsejar Strings concatenats complexos.
  • Separa les dades de la visualització: El HTML es pot fer dinàmic llegint un fitxer XML extern amb JS i omplint la web, en comptes de reescriure HTML cada cop.
  • Simplifica l'intercanvi: Format de text pla (plain text) llegible per sistemes incompatibles entre ells (Windows, Linux, Mac, Mòbils).

3. Estructura i Regles Sintàctiques

L'Estructura d'un XML

<!-- XML Prolog -->
<?xml version="1.0" encoding="UTF-8"?> 

<!-- Root element (Element Arrel Únic) -->
<note private="true"> 
  <from>Alice Smith</from>
  <to>Robert Jones</to>
  <message>Don't forget me!</message>
</note>

Tot document ha de tenir un sol element arrel que envolti tota la resta.

Regles Estrictes

  • Tancament obligatori: <p>Text</p>. (A diferència del HTML on <br> pot anar sol, en XML ha de ser <br/>).
  • Case Sensitive: <Letter> és diferent de <letter>.
  • Aniuament correcte: <b><i>Text</i></b> és correcte. Entrecreuar etiquetes donarà error.
  • Atributs amb cometes: <note date="12/11/2007">.
  • Caràcters Especials: No es pot posar < al text lliurement. Cal usar Entitats: &lt;, &gt;, &amp;.

4. Disseny: Elements vs Atributs

L'XML permet representar la mateixa dada de dues maneres:

1. Com a Atribut

<person sex="female">
  <firstname>Anna</firstname>
  <lastname>Smith</lastname>
</person>

2. Com a Element (Node fill)

<person>
  <sex>female</sex>
  <firstname>Anna</firstname>
  <lastname>Smith</lastname>
</person>

Quan usar cadascun?

En els dos casos es proporciona la mateixa informació. Com a regla de disseny general:

  • Les informacions més llargues i complexes (que poden contenir sub-dades) es transformen en Elements.
  • Els detalls més petits i les meta-dades (informació sobre la dada principal, tipus simples com ID, tipus d'arxiu, etc.) es transformen en Atributs.
Exemple d'Atribut per metadada:
<file type="gif">computer.gif</file>

5. Accedir a l'Arbre DOM-XML

El concepte clau: L'XML té un DOM idèntic al del HTML. Es compon de nodes pare, fills i germans.

<categories>
  <category>children</category>
  <category>computers</category>
</categories>

Propietats Històriques a recordar

Al DOM d'XML "pur", el text de dins d'un tag es considerava un fill en si mateix (un TextNode). Per arribar al text d'un node calia fer:
node.firstChild.nodeValue

Mapa de Navegació

ajax.responseXML
 └─ firstChild → <categories>
    ├─ firstChild → <category>
    │  └─ firstChild → "children"
    │
    └─ nextSibling → <category>
       └─ firstChild → "computers"

6. Pròleg i Validació Estricta (Schema)

Tot XML ben format comença amb el pròleg (<?xml version="1.0" encoding="UTF-8"?>). A més, l'ecosistema XML permet usar un Schema (XSD) per validar que l'estructura i els tipus de dades siguin 100% correctes abans de processar-los.

1. Les Dades (XML)

<?xml version="1.0" encoding="UTF-8"?>
<alumne>
    <nom>Anna</nom>
    <nota>8.5</nota>
</alumne>

2. Les Regles (XSD)

<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">
    <xs:element name="alumne">
        <xs:complexType>
            <xs:sequence>
                <xs:element name="nom" type="xs:string"/>
                <xs:element name="nota" type="xs:decimal"/>
            </xs:sequence>
        </xs:complexType>
    </xs:element>
</xs:schema>

7. Plantilles XML: Transformació a HTML (XSLT)

Per generar HTML directament des d'un document XML, l'estàndard natiu és XSLT (Extensible Stylesheet Language Transformations).

Com funciona?

Actua com una plantilla on definim, mitjançant etiquetes com <xsl:template>, com s'ha de renderitzar cada element de l'arbre XML original cap al nou format (HTML).

Exemple de full d'estils XSLT

<?xml version="1.0" encoding="UTF-8"?>
<xsl:stylesheet version="1.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
  
    <!-- Plantilla per l'element arrel -->
    <xsl:template match="/alumne">
        <html>
            <body>
                <h2>Expedient Acadèmic</h2>
                <div class="perfil">
                    <p><strong>Alumne:</strong> <xsl:value-of select="nom"/></p>
                    <p><strong>Nota:</strong> <xsl:value-of select="nota"/></p>
                </div>
            </body>
        </html>
    </xsl:template>

</xsl:stylesheet>

8. JavaScript i els Nodes XML

Propietats del DOM XML (Llistat complet)

  • Propietats: nodeName, nodeType, nodeValue, attributes, firstChild, lastChild, childNodes, nextSibling, previousSibling, parentNode.
  • Mètodes: getElementsByTagName, getAttribute, hasChildNodes, appendChild, removeChild.

Limitacions històriques respecte a l'HTML: No es podia usar getElementById() fàcilment (l'XML no sap què és un ID llevat que tingui DTD), ni es podia utilitzar el comodí innerHTML per extreure tot el contingut en format text.

Sintaxi per recuperar Dades

// 1. Trobar nodes per Etiqueta (Array)
var elms = node.getElementsByTagName("tag");

// 2. Recuperar el Text
var text = node.firstChild.nodeValue; 
// O l'alternativa moderna millorada:
var text = node.textContent;

// 3. Llegir Atributs
var attrVal = node.getAttribute("nom_atribut");

JS Modern

Avui dia podem utilitzar Selectors CSS també en documents XML:

node.querySelectorAll("book > title");

9. Parsejar XML (L'enfocament històric)

1. Utilitzant Prototype.js (Anys 2000)

La llibreria retornava l'arbre a l'objecte ajax.responseXML.

// Quant guanya un advocat segons l'XML?
var lawyer = ajax.responseXML.getElementsByTagName("lawyer")[0];
var salary = lawyer.getAttribute("money"); // "99999.00"

// Trobar el càrrec d'un treballador aniuat
var emps = ajax.responseXML.getElementsByTagName("employee");
var pos = emps[0].getElementsByTagName("job_position")[0]
                 .getAttribute("model"); // "director"

2. Utilitzant jQuery (Més fàcil)

jQuery permetia parsejar el document i fer "find" ràpidament.

$.ajax({
  type: "GET",
  url: "BookList.xml",
  dataType: "xml",
  success: function(xml) {
    // Iterar sobre cada node <Book>
    $(xml).find('Book').each(function() {
      var titol = $(this).find('Title').text();
      var pub = $(this).find('Publisher').text();
      
      $("<li></li>").html(titol + ", " + pub)
                   .appendTo("#dvContent ul");
    });
  }
});

11.Parsejar XML amb JS: La Versió Actual

Avui en dia, la forma estàndard i moderna per convertir una cadena de text XML en un document manipulable és utilitzant la classe nativa DOMParser.

El poder del DOM Modern

Un cop parsejat, l'objecte resultant és un XMLDocument. Això significa que podem oblidar-nos de navegar node a node manualment i utilitzar els selectors CSS que ja coneixem (com querySelector()).

Codi JS (DOMParser)

// 1. Text XML (ex: resposta d'un fetch)
const xmlString = `<dades>
    <element id="1">Informació clau</element>
</dades>`;

// 2. Instanciem el parser
const parser = new DOMParser();

// 3. Parsejem indicant el tipus MIME
const xmlDoc = parser.parseFromString(xmlString, "application/xml");

// 4. Usem selectors moderns per extreure text!
const text = xmlDoc.querySelector("element[id='1']").textContent;

console.log(text); // "Informació clau"

12. PHP: L'Escriptura d'XML

La classe DOMDocument de PHP

Molt semblant al JS, PHP construeix el document per parts (Nodes):

  • createElement(tag): Crea un nou element XML.
  • createTextNode(text): Crea el contingut de l'element.
  • setAttribute(name, value): Defineix atributs.
  • appendChild(node): L'uneix a l'arbre principal.
  • saveXML(): Retorna o imprimeix l'XML complet construït, incloent-hi el pròleg `<?xml version="1.0"?>`.

Construint Nodes d'un Llibre

<?php
// Amb codificació per suportar caràcters espanyols/catalans
$xmldoc = new DOMDocument('1.0', 'UTF-8');

// Root Element <books>
$books_tag = $xmldoc->createElement("books");
$xmldoc->appendChild($books_tag);

// Sub-element <book>
$book_tag = $xmldoc->createElement("book"); 
$book_tag->setAttribute("title", "Harry Potter"); 
$book_tag->setAttribute("author", "J.K Rowling");

$books_tag->appendChild($book_tag);

// Imprimir cap al client (AJAX ho rebrà)
print $xmldoc->saveXML();
?>

13. PHP: Servidor i DOMElement (Lector)

Com interactuar amb nodes en PHP?

La classe DOMElement representa cada node i té mètodes calcats al JavaScript antic: tagName, nodeValue, parentNode, childNodes.

Podem utilitzar-ho per fer que PHP llegeixi un fitxer XML del disc (load()), el filtri, i només retorni l'HTML al client.

El Servidor getcd.php de l'exemple

<?php
$q = $_GET["q"];
$xmlDoc = new DOMDocument();
$xmlDoc->load("cd_catalog.xml");
$x = $xmlDoc->getElementsByTagName('ARTIST');

for ($i=0; $i<=$x->length-1; $i++) {
  // Processar només si és element (nodeType == 1)
  if ($x->item($i)->nodeType==1) {
    if ($x->item($i)->childNodes->item(0)->nodeValue == $q) {
      // Trobat! Anem cap al pare <CD> per llegir-ho tot
      $y = ($x->item($i)->parentNode);
      ... echo del HTML basat en els nodes del CD
    }
  }
}
?>

14. Autoavaluació: Conceptes XML

Comprova el que saps sobre les regles del llenguatge XML.

Quin error greu hi ha en aquesta línia?
<nota data=10/05/2018>
Tots els atributs de l'XML han d'anar obligatòriament entre cometes dobles o simples ("10/05/2018"). A HTML5 això es perdonava, a XML llençarà un error fatal de parseig.
Quin seria el resultat del següent codi?
<MESSage>Hello</message>
Error d'etiquetes no coincidents. A l'XML, els tags són estrictament "Case Sensitive" (sensibles a majúscules/minúscules). El tag d'inici i tancament han de ser completament idèntics.
Com escrivim una condició amb el símbol 'Menor que' (<) com "A < B"?
El parser interpretarà < com l'inici d'una nova etiqueta. Cal utilitzar l'entitat HTML corresponent: A &lt; B.
Com accedim en JavaScript Vanilla al contingut de text d'un Node de forma moderna?
Antigament es feia: node.firstChild.nodeValue.
L'API moderna recomanada és: node.textContent.
