1. Transicions CSS3

El fi de les animacions per JS

Antigament utilitzàvem JavaScript per moure objectes pas a pas o canviar-ne l'opacitat. Això consumia molta CPU i bloquejava el fil principal.

Amb CSS3 Transitions, el canvi d'estat d'un element és processat directament per la targeta gràfica (GPU), sent extremadament fluid i alliberant el navegador.

Sintaxi bàsica:
transition: [propietat] [durada] [corba] [retard];

Exemple Pràctic (Hover)

El canvi es dispara automàticament quan s'aplica una pseudo-classe com :hover o quan s'afegeix una classe via JS.

.boto {
  background-color: blue;
  transform: scale(1);
  /* Anima qualsevol canvi durant 0.3 segons */
  transition: all 0.3s ease-in-out;
}

.boto:hover {
  background-color: red;
  transform: scale(1.1); /* Es fa més gran fluidament */
}

2. Animacions d'Alta Complexitat

@keyframes

Si una transició serveix per anar d'un punt A a un punt B de cop, els Keyframes permeten definir una línia de temps complexa amb múltiples parades (0%, 50%, 100%).

  • Es reprodueixen de forma autònoma un cop aplicades.
  • Poden ser infinites amb la propietat infinite.
  • Permeten alternar direccions d'anada i tornada (alternate).

Definir i Executar

/* 1. Definim la línia de temps de l'animació */
@keyframes batec {
  0%   { transform: scale(1); }
  50%  { transform: scale(1.2); }
  100% { transform: scale(1); }
}

/* 2. L'apliquem a l'element */
.cor {
  animation-name: batec;
  animation-duration: 1s;
  animation-iteration-count: infinite;
}

3. Nous Inputs Natius d'HTML5

Adéu a ginys externs complexos

Abans necessitàvem llibreries pesades només per mostrar un calendari o un control de rang. HTML5 va estandarditzar la creació de controls de formulari que es renderitzen de forma nativa segons el Sistema Operatiu (iOS, Android, Windows).

  • Data i Hora: Al mòbil, el navegador obre automàticament l'esfera tàctil.
  • Rang i Color: Apareixen selectors natius de paletes i cursors sense picar JS addicional.

Els Tipus d'Input Natius

Codi HTMLResultat Visual
type="date"📅 Calendari complet (Datepicker)
type="time"⌚ Selector d'hores i minuts
type="range"🎚️ Slider lliscant (ex: volum o preu)
type="number"🔢 Spinner amb fletxes d'increment
type="color"🎨 Paleta de colors del sistema

4. Controls de UI Sense JavaScript

Pestanyes Expansibles (Accordion)

Substitueix els antics scripts tipus "slideToggle" per un funcionament 100% natiu i accessible. Fent clic al <summary>, el bloc de <details> es desplega automàticament.

<details>
  <summary>Com funciona l'enviament?</summary>
  <p>Els enviaments triguen 24h a la península.</p>
</details>

Barres de Progrés i Mesura

Etiquetes semàntiques que els navegadors renderitzen gràficament amb colors d'alerta automàtics segons els llindars establerts.

<!-- Barra de càrrega típica -->
<progress max="100" value="70">70%</progress>

<!-- Indicador tipus velocímetre (verd, groc, vermell) -->
<meter min="0" max="100" 
       low="30" high="80" value="85">
  85 (Zona de Perill)
</meter>

5. Autocompletar i Finestres Modals

El <datalist>

Proporciona un menú de "Suggeriments" autocompletables a qualsevol input de text, respectant el filtre de cerca i l'estil natiu.

<input type="text" list="fruites">

<datalist id="fruites">
  <option value="Poma">
  <option value="Plàtan">
  <option value="Pera">
</datalist>

El <dialog> (Finestres Modals)

Oblida't de gestionar fons foscos, z-index o bloquejar l'scroll. El component <dialog> ho fa sol amb una simple crida JavaScript.

<dialog id="meuDialog">
  <h3>Avís Important</h3>
  <button onclick="meuDialog.close()">Tancar</button>
</dialog>

<script>
  // L'obre bloquejant la resta de la pàgina (Modal)
  document.getElementById('meuDialog').showModal();
</script>

6. Drag and Drop API (Nativa)

Fent objectes Arrossegables

Qualsevol element de la web es pot fer arrossegable simplement afegint l'atribut draggable="true".

<div id="caixa1" draggable="true">
  Agafa'm!
</div>

Enviant Dades (DataTransfer)

Quan l'usuari fa clic i arrossega, hem de "guardar" l'identificador de l'element dins l'objecte especial dataTransfer per saber què estem movent.

const caixa = document.getElementById('caixa1');

caixa.addEventListener('dragstart', (e) => {
  // Guardem l'ID de l'element mogut
  e.dataTransfer.setData('text/plain', e.target.id);
});

La Zona de Recepció (Dropzone)

Per defecte, el navegador prohibeix deixar caure elements. Hem de deshabilitar aquesta prohibició a l'esdeveniment dragover.

const zona = document.getElementById('zonaReceptora');

// 1. Obrir les portes a rebre elements
zona.addEventListener('dragover', (e) => {
  e.preventDefault(); // Crucial per permetre el drop!
});

// 2. Quan el deixen a sobre
zona.addEventListener('drop', (e) => {
  e.preventDefault();
  // Recuperem l'ID que havíem guardat
  const idGuardat = e.dataTransfer.getData('text/plain');
  const elementMogut = document.getElementById(idGuardat);
  
  // Movem l'element físicament a dins de la zona
  zona.appendChild(elementMogut);
});
